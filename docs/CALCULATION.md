# 计算与统计约定

## 定价

`S_base = C − P + K exp(−rT)`，每股单位。`T` 为 pricingAt 与快照 valuationAt 的UTC秒差 / (365×86400)，或仅使用人工 days/365。到期日盘中不自动设T=0。历史预览保留原 valuationAt。过期、未知时间且无明确假设返回null。

当前模型 `parity-median-v3-centered` 仅计算 LAST 和 MID 两种模式。LAST 分别使用 Call / Put 最新成交价；MID 分别使用两条腿的买卖中间价。缺失值不借用其他口径。人工 reportedMid 仅用于 MANUAL 源，不虚构盘口。

默认从离正股 Last 最近的行权价开始，取前 3 档＋自身＋后 3 档，等距时取较低行权价，按行权价升序输出。先选档再验报价，缺失不补远档。中心档不等于严格平值；两侧均为 0 时不选档。

每档贡献一个反推参考值，以中位数 rawMedian 汇总，显示 min、max；validatedMedian 只含质量合格档。偶数样本取中间两数平均，空样本返回 null。不再输出均值。样本不足时显示可计算数量/请求数量，不能称为完整七档。

真实合成盘口下界 `C_bid-P_ask+PV(K)`、上界 `C_ask-P_bid+PV(K)` 保留用于解释盘口；不是可保证实现的套利或置信区间。

三档 Call 的复制参考价、非等距权重及完整升级说明见 [七档中位数模型](MEDIAN_MODEL.md)。

配对比较标的、期限、K、币种、行权方式、结算类型、乘数、交割规格、调整标记和时间元数据。调整合约拒绝，单位不为每股拒绝。负数、缺值、交叉盘口、时间戳缺失、过期、不同事件时间差等有独立排除原因；异常原值尽量保留，不按价差大小删数据。非有限输入在Pydantic边界拒绝并返回422，不以0代替。

独立股息输出 `adjustedValue=S_base+dividendPV`，版本parity-dividend-v1；未知股息为null。基础反推值与股息修正结果分别展示。
