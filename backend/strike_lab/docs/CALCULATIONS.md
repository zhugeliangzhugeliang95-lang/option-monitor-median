# 附件算法与复核

## 三档复制比较

对目标档 i，用另外两档 j、k：

```
w_j = (K_k - K_i) / (K_k - K_j)
w_k = 1 - w_j
C_ref_i = P_i + w_j (C_j - P_j) + w_k (C_k - P_k)
premium_i = (C_i - C_ref_i) / C_ref_i × 100%
```

权重满足和为 1、加权行权价等于目标行权价，故该复制表达式中行权价折现项消去，参考价不依赖利率。边缘目标可能产生负权重，表示公式中的空头腿。此处仅展示估值组成，不下单。

参考价非正、缺少任一所需报价或合约规格不一致时不排名。相对溢价较低者列前；有正股现价时以最近行权价为中心（等距取较低档），选前后各三档。每档用左右邻档作参照，两端用同侧最近两档。七档全部可计算时统一排名。只有三档历史输入的附件案例保留组内排名。复制参考价也由市场报价推导，并非独立证实的“真实价值”。

附件 GOOG 2026-10-30 案例，到期日 2026-11-06：

| K | Call | Put | 复制参考价 | 相对溢价 |
|---|---|---|---|---|
|275|7.59|3.67|7.400|2.57%|
|277.5|5.85|4.72|5.945|-1.60%|
|280|4.66|6.13|4.470|4.25%|

此组下 277.5 的相对溢价最低。附件没有提供正股现价或盘口，示例不填写这些字段。
